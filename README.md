# 在线课程自动连播助手

一个通用的 Tampermonkey 油猴脚本：自动帮你在在线学习平台上按顺序刷完课程视频。

> ⚠️ 仅供个人学习交流与自动化辅助测试使用，请遵守所在平台的学习规定，合理安排学习进度。

## 功能

- **自动连播**：课程列表 → 自动点进 → 自动播放 → 播完自动返回 → 下一门，循环直到全部完成
- **模拟点击驱动**：完整的 pointer/mouse 事件序列 + 父链补点，兼容 Vue/React SPA 的点击监听；点击后校验路由是否变化，失败自动走兜底
- **防挂机弹窗**：自动点击"继续播放/继续学习/知道了"类提示按钮；遇到**随堂测验自动暂停并提醒**（不代答）
- **切后台不暂停**：劫持页面可见性检测，最小化窗口、切标签页照常播放
- **倍速**：默认 2 倍速（模拟点击播放器倍速菜单 + 直接钉住 `playbackRate` 双保险），面板一键切回原速
- **列表自适应**：动态识别课程列表（卡片式/表格式均可），支持懒加载滚动探测和分页列表自动翻页
- **防重复**：已点课程记入持久化清单，第一遍刷完后自动复查未到 100% 的课程（最多两遍，防死循环）
- **悬浮面板**：启动/暂停、静音开关、倍速开关、运行日志，右下角常驻

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Edge/Chrome/Firefox 均可）
2. Tampermonkey → 添加新脚本 → 粘贴 `course-autoplay.user.js` 内容 → 保存

## 配置（必做）

把脚本头部的 `@match` 改成你的学习平台域名：

```
// @match https://www.your-platform.com/*
```

如果视频播放器嵌在第三方域名的 iframe 里，再为该域名加一条 `@match`。

## 使用

1. 打开课程列表页，右下角出现「🎓 连播助手」面板
2. 点 **▶ 启动**，脚本自动循环刷课
3. 面板按钮：⏸ 暂停 / 🔇 声音开关 / ⚡ 倍速开关（1x ↔ 2x）

## 原理说明

- 脚本只做**操作自动化**（模拟点击、自动恢复播放），不篡改播放进度、不伪造心跳上报——进度走的是播放器自己的真实上报通道
- 倍速通过标准 `playbackRate` 实现，与播放器菜单选倍速等效
- 服务端可见的只有正常的进度上报，输入方式（手点/脚本点）在网络层面无区别
